Verdict. The six demos may be enabled on GitHub Pages as they stand in the working trees. Nothing in
this amendment weakens the Sprint 1 posture: every page keeps a strict meta CSP with no inline code,
the only network destinations are the page's own files and, for runtime alone, an https manifest URL
the user types and allow-lists first, the signing demo never persists or prints its key, storage
demos stay inside their own prefixes on the shared origin, dockit's worker now cleans up only its own
caches, and every workflow runs with read-only checkout credentials and a deploy job limited to
`pages: write` + `id-token: write`. The items left open are a Range check the owner can only make
after the first deploy (S1-045), one installer digest row to re-hash when GitHub's release CDN
recovers (S1-046) and two pre-existing pagetriage workflows outside this run's scope (S1-047); none of
them blocks enabling Pages. What the demos do not and cannot provide on Pages, frame-ancestors,
COOP/COEP, cache control and any origin isolation between demos, is recorded in S1-041 and S1-044 for
the pre-pilot checklist, where real users and real documents will need a host that sets headers.
