# Pre-pilot security checklist

What must be true before any customer laptop runs an Airplane Mode Labs build with real documents.
Owner: the founder unless a lane is named. Status column: Open, Done, N/A. Nothing in this list is
a Sprint 1 deliverable; it is the gate between the engineering sprints and the first pilot.

| #   | Item                                                                                                                                                                                                                                                                                                                                                                                                     | Evidence required                                                                                      | Owner      | Status |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ---------- | ------ |
| 1   | **Real signing key and custody.** Generate the first production Ed25519 key with `cp-sign keygen` on an offline machine or in an HSM/OS keychain; keep an offline root and an online signing key; record who holds each, where backups live, and the rotation procedure. The RFC 8032 test key must not appear in any production trust set (`allowTestKeys` is never set in a shipped app).              | keyId of the production key, custody record, `grep -r 21fe31df` over the shipped bundle prints nothing | owner / D6 | Open   |
| 2   | **Key revocation path.** Until S1-001 lands, pilots use `--expires-days 30` or shorter and an app-release path to replace the trust set within 24 h.                                                                                                                                                                                                                                                     | Signed manifests show `expiresAt` <= 30 days; release runbook                                          | owner / D1 | Open   |
| 3   | **TLS at hosting.** Manifest and asset host serve https only with a current certificate; HSTS enabled; no http fallback. The runtime refuses http except to loopback, so a misconfigured host fails closed.                                                                                                                                                                                              | `curl -I` of the manifest and one asset over https; HSTS header present                                | owner      | Open   |
| 4   | **CSP and isolation headers at hosting.** The server sends `Content-Security-Policy` with the dockit directives plus `frame-ancestors 'none'`, `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Embedder-Policy: require-corp` (and `Cross-Origin-Resource-Policy` on assets), `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`. The meta tag cannot set these.                 | Header dump of `/` and `/assets/<x>`; Playwright assertion in the deployment smoke test                | owner / D5 | Open   |
| 5   | **Dedicated origin.** dockit runs on its own origin (no other app, no shared subpath) so the same-origin co-tenant risk (S1-006) is bounded to dockit's own code.                                                                                                                                                                                                                                        | Hosting record                                                                                         | owner      | Open   |
